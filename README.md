# 基于物理信息的 T 型管流场深度学习代理模型
(Physics-Informed T-Pipe Fluid Surrogate Model)

本项目是一个专门针对**T型管道内不可压缩流体**（压力场与速度场）预测定制的深度学习代理模型框架。
模型全面清除了实验性的冗余代码，并采用 **CNN-Transformer 混合架构 (TransUNet风格)** 构建，深度融合了 **物理信息神经网络 (PINN)** 约束。在保证极高推理速度与精度（$R^2 > 0.93$）的同时，严格遵守了质量守恒与动量守恒等宏观物理定理。

---

## 一、 核心技术特性

- **TransUNet 架构与全局 Transformer 瓶颈**：在 DenseED 编码器与解码器极深处植入了多头自注意力机制 (Multi-head Self-Attention)。有效克服了纯 CNN 局部感受野受限的问题，能够秒级捕捉 T 型管入口对死角区域的回流和流体拓扑结构影响。
- **自动维度推导与多维张量防御**：底层代码经过深度重构，完美兼容 4D (2D流场) 和 5D (3D流场) 数据。归一化与通道推导过程自动适应 `sensor_input` 稀疏传感器输入，消除了各种极其隐蔽的硬编码引起的张量维度崩溃Bug。
- **物理偏微分方程约束 (PINN)**：突破纯数据驱动的均方误差 (MSE) 限制，内部架构全部替换为高阶平滑的 **SiLU** 激活函数，确保二阶导数连续无断裂：
  - **连续性方程约束**：最小化散度 ($\nabla \cdot v=0$)，保证预测流场的不可压缩特性。
  - **Navier-Stokes动量约束**：通过自动微分与有限差分法，引导预测结果严格符合稳态动量守恒方程。
- **严格的计算边界掩码 (T-Mask)**：内置定制的 T型几何域切割器，所有的特征提取、物理损失检查与最后梯度回传，均被严格限制在真实管壁内部。

## 二、 项目核心结构说明

```text
.
├── dataset/                # 数据集目录 (存放训练/测试用的结构化 HDF5 流场数据)
├── experiments/            # 实验输出目录 (自动归档训练日志 args.txt、模型权重 checkpoints/ 及出图)
├── models/                 # 代理模型架构库
│   ├── dense_ed.py         # 融合全局 Transformer 瓶颈的 2D DenseED 核心模型
│   └── dense_ed_3d.py      # 对应的 3D 体素代理模型拓展版本 (搭载 3D Transformer)
├── utils/                  # 核心计算与数据加载算子
│   ├── physics_loss.py     # 物理损失模块 (包含散度、NS方程残差的偏导数与有限差分逻辑)
│   ├── plot.py / plot_3d.py# 轻量化、对齐真实值极值的自动出图脚本 (已剔除废弃贝叶斯作图)
│   └── load_data.py / ...  # 具备自适应归一化维度推断的 HDF5 数据流加载器
├── train.py                # 主干训练脚本 (管理前向传播、联合物理/数据损失计算与调度)
├── surrogate_predict.py    # 脱机推理脚本 (加载已训好的模型权重，对新工况进行高速单张推演)
├── diagnose.py             # 智能诊断工具 (评估模型 R²、RMSE 误差并打印排优报告)
├── gui_trainer.py          # 图形化训练面板 (Tkinter UI，支持一键调参启停)
├── args.py / args_3d.py    # 2D/3D 通用超参数统一定义与解析逻辑
└── scripts/                # 环境初始化、数据与预训练权重下载 Shell 脚本
```

## 三、 标准工作流程 / Workflow

### 1. 环境准备
确保您的 Python 环境中已经安装了以下核心依赖：
```bash
pip install torch numpy h5py matplotlib
```
*(提示: 若要使用 GUI 图形化操作面板，请确保 Python 环境配置了 `tkinter` 组件)*

### 2. 数据入库
将预先生成的 CFD 模拟数据集 (HDF5 格式) 拷贝至项目的 `dataset/` 路径下。
> 示例：`dataset/v_256.hdf5` 或 `dataset/p_v_256.hdf5`

### 3. 启动训练
项目提供以下模式进行模型与PINN混合训练。运行日志与模型权重会按时间戳与代号分发到 `experiments/` 目录中：

**方案 A：使用纯命令行 (推荐，适合批处理与服务器后台执行)**
```bash
python train.py --train-file dataset/v_256.hdf5 --test-file dataset/v_256.hdf5 --epochs 200 --batch-size 8
```

**方案 B：使用图形化界面 (适合可视化调参)**
运行以下命令调出操作控制台：
```bash
python gui_trainer.py
```
在界面中选择好数据集和指定迭代次数后，点击“开始训练”。

### 4. 训练监测与智能诊断
训练结束或中途退出后，可通过专用的智能体检器进行全面诊断：
```bash
python diagnose.py
```
它能够：
- 自动读取最新的训练结果日志。
- 输出中文解读报告（$R^2$ 得分、RMSE 误差及分项 Loss 走向）并给出模型优化侧写建议。

### 5. 结果可视化分析
预测程序会自动在训练验证阶段绘制真实值与代理模型预测值的高精度伪彩对比图。
- **图像路径**：`experiments/<专属实验名>/training/predictions/`
- **图像阅读说明**：报告由上往下分别为：CFD 基准真实流场 (Row 1)；代理模型预测流场 (Row 2)；绝对误差残差图 (Row 3)。如残差图体现出极淡乃至趋于 0 的纯色，则表明物理与数据双重拟合质量极佳。
